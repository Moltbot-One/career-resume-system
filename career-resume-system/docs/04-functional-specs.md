## 1. 产品概述

### 1.1 产品愿景

**CareerCompass AI** 是中国领先的智能职业规划与简历制作平台，致力于通过人工智能技术和职业科学的结合，帮助每一位大学生和求职者：

- **发现**：发现自己的职业潜能和优势
- **规划**：制定清晰的职业发展路径
- **准备**：打造专业、有竞争力的求职材料
- **成功**：实现职业目标，获得理想的工作机会

### 1.2 目标用户画像

#### 1.2.1 核心用户：在校大学生

```
用户画像:
├── 年龄: 18-22岁
├── 年级: 大一 ~ 大四
├── 学历: 本科/专科
├── 特征:
│   ├── 对未来职业方向不明确
│   ├── 缺乏职场经验和求职技巧
│   ├── 简历内容空白，不知道写什么
│   ├── 对自身优势认知不足
│   └── 渴望专业的职业指导
└── 核心需求:
    ├── 职业方向探索与定位
    ├── 简历内容填充与优化
    ├── 面试技巧学习
    └── 职业发展建议
```

#### 1.2.2 应届毕业生

```
用户画像:
├── 年龄: 22-24岁
├── 状态: 即将毕业或刚毕业
├── 特征:
│   ├── 正在积极找工作
│   ├── 简历投递石沉大海
│   ├── 面试机会少，不知道问题出在哪里
│   ├── 希望快速提升简历质量
│   └── 时间紧迫，压力大
└── 核心需求:
    ├── 快速生成优质简历
    ├── 简历优化建议
    ├── 职位匹配与推荐
    └── 面试模拟与准备
```

#### 1.2.3 职场转型者

```
用户画像:
├── 年龄: 24-35岁
├── 工作经验: 1-10年
├── 特征:
│   ├── 对现有工作不满意，考虑转行
│   ├── 不知道适合什么方向
│   ├── 缺乏目标行业经验
│   ├── 简历不会突出转型优势
│   └── 需要职业转型规划
└── 核心需求:
    ├── 职业转型评估
    ├── 技能差距分析
    ├── 转型简历优化
    └── 行业趋势分析
```

#### 1.2.4 企业/高校客户

```
用户画像:
├── 用户类型: 高校就业中心、企业HR、培训机构
├── 特征:
│   ├── 需要批量服务学生/员工
│   ├── 需要数据分析和管理功能
│   ├── 需要定制化服务
│   └── 需要品牌展示
└── 核心需求:
    ├── 批量职业测评
    ├── 批量简历优化
    ├── 数据分析看板
    └── 企业品牌定制
```

### 1.3 核心价值主张

#### 1.3.1 对个人用户的价值

```
四大核心价值:

1. AI驱动的个性化服务
   ├── 基于用户画像的智能推荐
   ├── 千人千面的简历内容生成
   ├── 个性化的职业发展建议
   └── 持续学习和优化

2. 科学的人才测评体系
   ├── 经过验证的职业性格测评
   ├── 专业的能力评估模型
   ├── 多维度的职业匹配
   └── 可视化的测评报告

3. 全流程求职陪伴
   ├── 职业探索 → 能力提升
   ├── 简历制作 → 职位申请
   ├── 面试准备 → offer选择
   └── 持续的职业发展支持

4. 数据驱动的优化
   ├── 持续追踪求职效果
   ├── A/B测试优化算法
   ├── 用户反馈驱动迭代
   └── 行业数据洞察
```

#### 1.3.2 对企业客户的价值

```
企业客户价值:

1. 提升就业/招聘效率
   ├── 批量学生/员工测评
   ├── 批量简历优化
   ├── 人才匹配推荐
   └── 数据分析洞察

2. 降低培训成本
   ├── 标准化的职业指导
   ├── 自动化的简历优化
   ├── 数据化的效果追踪
   └── 持续的能力提升

3. 增强品牌影响力
   ├── 企业品牌定制
   ├── 专属服务页面
   ├── 招聘信息展示
   └── 校企合作展示
```

### 2.2 功能模块优先级划分

#### 2.2.1 MoSCoW优先级划分

| 优先级 | 说明 | 功能模块 |
|--------|------|---------|

| **Won't Have (这次不做)** | 本期不做，后续规划 | 视频简历、AI模拟面试、企业招聘功能、社交功能 |

## 3. 用户角色与权限

### 3.1 用户角色定义

```

#### 3.1.2 角色详细说明

| 角色 | 描述 | 典型用户 | 数量比例 |
|------|------|---------|---------|
| **游客 (Guest)** | 未登录用户，只能浏览公开内容 | 首次访问用户 | ~30% |
| **免费用户 (Free)** | 已注册，可使用基础功能 | 普通学生/求职者 | ~65% |
| **付费会员 (Premium)** | 购买会员，享受完整功能 | 活跃用户 | ~4.5% |
| **企业用户 (Enterprise)** | 企业/高校客户，批量服务 | 高校就业中心、企业HR | ~0.5% |
| **管理员 (Admin)** | 平台运营管理人员 | 产品、运营、技术 | <0.1% |

```

   ↓

### 5.3 MBTI职业性格测评

#### 5.3.1 测评原理

MBTI (Myers-Briggs Type Indicator) 是全球最流行的职业性格测评工具，通过4个维度将人分为16种人格类型：

```
MBTI四个维度:

1. 精力来源 (E-I)
   ├─ E (Extraversion) 外向型: 从与人互动中获取能量
   │  特征: 善于社交、行动导向、善于表达
   │  适合职业: 销售、市场、管理、咨询、教育
   │
   └─ I (Introversion) 内向型: 从独处和思考中获取能量
      特征: 善于思考、深度专注、内心丰富
      适合职业: 研发、设计、分析、写作、科研

2. 信息获取 (S-N)
   ├─ S (Sensing) 实感型: 关注具体事实和细节
   │  特征: 务实、细致、经验导向、注重现实
   │  适合职业: 会计、工程、操作、行政、质检
   │
   └─ N (Intuition) 直觉型: 关注模式和可能性
      特征: 创新、想象力强、全局思维、未来导向
      适合职业: 产品、设计、战略、研发、创业

3. 决策方式 (T-F)
   ├─ T (Thinking) 思考型: 基于逻辑和分析做决策
   │  特征: 客观、理性、公正、讲究原则
   │  适合职业: 法律、金融、工程、管理、科研
   │
   └─ F (Feeling) 情感型: 基于价值观和情感做决策
      特征: 感性、同理心强、善于协调、注重人际关系
      适合职业: 人力资源、咨询、教育、客服、社工

4. 生活态度 (J-P)
   ├─ J (Judging) 判断型: 喜欢计划和组织
   │  特征: 有条理、守时、喜欢确定性、善于计划
   │  适合职业: 管理、项目管理、财务、行政、法律
   │
   └─ P (Perceiving) 感知型: 喜欢灵活和随机
      特征: 灵活、适应强、好奇心强、开放性高
      适合职业: 创意、设计、咨询、研究、创业
```

#### 5.3.2 16种人格类型与职业匹配

### 5.4 霍兰德职业兴趣测评

#### 5.4.1 测评原理

霍兰德职业兴趣理论将人的职业兴趣分为6种类型，不同类型适合不同的职业：

```
霍兰德6种兴趣类型:

R (Realistic) 现实型: 喜欢动手操作、技术、机械
   特征: 务实、喜欢具体事物、动手能力强
   适合职业: 工程师、技术员、机械操作、建筑、农林

I (Investigative) 研究型: 喜欢思考、研究、分析
   特征: 好奇、分析能力强、求知欲强
   适合职业: 科研、数据分析、研发、医疗、数学

A (Artistic) 艺术型: 喜欢创造、表达、审美
   特征: 想象力丰富、情感细腻、追求独特
   适合职业: 设计、写作、艺术、媒体、音乐

S (Social) 社会型: 喜欢与人交往、帮助他人
   特征: 友善、热心、善于沟通、有同理心
   适合职业: 教育、人力资源、咨询、社工、医疗

E (Enterprising) 企业型: 喜欢影响、领导、竞争
   特征: 自信、有野心、善于说服、追求成就
   适合职业: 管理、销售、创业、律师、金融

C (Conventional) 常规型: 喜欢有序、规范、数据
   特征: 细致、有条理、责任心强、遵从规则
   适合职业: 会计、行政、财务、银行、档案管理
```

#### 5.4.2 职业兴趣代码

CareerCompass AI 设计原则:
